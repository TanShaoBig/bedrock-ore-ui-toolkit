# Ore UI 风格

以基岩版 Ore UI 设置页为视觉基准。按同一 GUI 缩放与输入状态核对外轮廓、亮边、底影、图标相对字号、行间距和按压位移。用[实验室实机画面](references/gallery_numbers.png)检查导航与内容布局，用[贴图总览](references/texture_catalog.png)选择控件状态。

先确定玩家在这个界面要做什么，沿用目标项目的入口、语言、业务动作和输入方式。用户只说“用 OreUI 风格”时，以下规则就是默认标准。已有页面换肤时，保留控件路径、事件和存档含义；必须调整层级时，同步检查调用方。

## 选择页面骨架

- **单个模组的设置页**用浅灰横顶栏，左端返回、标题相对整页居中。多分类时，左侧约占宽度的五分之一，用小方图标配短标签，左栏当前行持续显示亮灰面和上下边线。图标用等大的方槽，文字共用左边线。宽屏多分类设置可参考国际版约三分之一宽的导航。点击分类切换右侧内容，移开指针后保留当前行。顶栏固定，设置列表在自己的视口里滚动。
- **多模组设置中心**有“模组或客户端/服务端 → 分类 → 具体选项”三级时，宽屏可以同时显示三栏。最左列呈现对象，中列呈现该对象的分类，右列给设置。窄屏按层级进入与返回，保留当前对象和分类。黄色提示只在玩家需要知道设置作用域等信息时出现。
- **单页、弹窗、HUD 或工具面板**按实际空间保留必要信息。使用同套文字层级、方角和操作色；只有存在同级目的地时才设置导航栏。

## 组织一行设置

标题和说明共用左边线，说明用较小的浅灰字。右侧的小控件共用右边线。开关、短按钮、短数字框可以与说明并排。滑杆或多个互斥选项放在文字下方占满行宽，滑杆的当前值放在标题行末。长中文说明自然换行并撑高该行，窄屏优先把操作移到下一行。分组用标题与水平分隔线，紧邻的行共用边界。

## 制作与验收

1. 从[色板与控件](references/style.md)取配色和状态。美术首选随附的[套件贴图库](assets/textures/ui/ore_style)，按[素材清单](references/artwork.md)找原图；缺失的状态可基于原图改色或组合。交付时列出直接使用、派生和其他来源，说明实际用到的外部美术。
2. 沿用目标项目的渲染方式。网易基岩版读取[JSON UI 接入](references/netease.md)，其中有可直接复用的按钮模板与贴图。网页或设计稿按同一组色值和逻辑像素绘制，位图按最近邻缩放。
   开关、连续与步进滑杆同时读取[控件动作规则](references/motion.md)，滑杆数值立即更新，方形手柄沿横轴阻尼跟随。分段选中的面和字持续下沉。用拖动中、反向、松手和移开指针后的状态验收。
3. 用实际业务文案检查宽屏与目标最窄视口。并排对照相应参考图，检查顶栏居中、文字与操作列的对齐、九宫格边缘等厚、滚动到最后一项仍能操作。分别检查选择后移开焦点、按下后松手、禁用和恢复时的外观及行为；有触屏时检查拖动滚动列表与调整滑杆是否会互相误触。说明实际验证过的环境。

## 玩家布局与稳定性验证

需要可调整按钮位置时，按[布局编辑器接入说明](references/hud-layout.md)复用实际 HUD、草稿编辑页与存储。用同一套位置换算处理配置回显、跨分辨率和分享码。

生成或改动网易 JSON UI 后，使用 Python 3 运行技能自带的 [validate_ui.py](scripts/validate_ui.py)。从技能目录运行以下命令，将示例路径替换为目标项目的实际包目录。

```sh
python -B scripts/validate_ui.py path/to/resource_pack --behavior-pack path/to/behavior_pack
python -B scripts/test_ui.py
```

校验器读取该包的 `ui/_ui_defs.json`，检查重复键、本包模板引用、同级重名控件、套件贴图，以及自定义滑杆普通态和悬停态所需的原生节点。项目自带纹理可重复传入 `--texture-prefix textures/你的目录/`。行为包检查覆盖同组的字面量 ViewBinder 名称，可用 `--binding-group` 指定组。跨包模板、动态生成的绑定和设备输入还要进游戏核对。组件被滚动区延迟创建时，先检查视口、内容路径和子节点，待可用时再应用当前值。对用户反馈记录客户端版本、输入方式、重现步骤和第一条相关日志。
