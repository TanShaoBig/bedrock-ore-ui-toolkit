# 玩家可调的 HUD 按钮布局

[运行时与编辑器模板](../assets/layout)包含一个可编辑两个按钮的完整示例。玩家从 HUD 或设置页进入，点选或拖动按钮，设置大小与不透明度。重置和导入只改变草稿，保存后才写客户端配置并刷新 HUD。取消或直接退出会丢弃草稿。底部的“切换按键”可选中被其他按钮遮住的项目。

## 接到已有模组

1. 将 `ore_layout.json` 与[控件样式](../assets/ui/ore_style.json)放进资源包的 `ui/` 并注册到 `_ui_defs.json`，复制样式使用的贴图库。按目标工程改命名空间及所有继承引用。
2. 将 `hud_editor.py` 与 `hud_layout.py` 放在同一个行为包 Python 包中。在 `BUTTONS` 填入稳定 ID、中文名、逻辑尺寸和默认位置。在编辑器与 HUD 的 `canvas` 下分别配置同 ID 的按钮，并将正式按钮动作绑定到项目已有回调。已有 HUD 可将 `LayoutHud` 的投影和刷新方法接到原有的 Create / Update，保留其业务事件。
3. 设置本项目独立的 `CONFIG_KEY`、布局码前缀、`HUD_NAMESPACE` 和 `HUD_NAME`。在客户端 `UiInitFinished` 注册 HUD 与编辑页。编辑页的 Python 类为 `你的包.hud_editor.LayoutEditor`，JSON 定义为 `ore_layout.editor`。入口调用 `PushScreen`，退出调用 `PopScreen`。模板中的 `#orelab_launcher.*` 为示例 HUD 动作。
4. 为已有按钮注册实际的容器和点击目标。示例假设两个目标都直接位于自由定位的 `/canvas/<id>`、采用左上锚点。嵌套控制器或其他锚点应映射到同一套坐标再应用。缩放同时改变可见控件与点击热区。不透明度下限默认为 20%，可保留独立设置入口以便玩家找回重叠按钮。

## 坐标、输入和存储

每轴保存 0–1 的可移动比例，实际左上坐标等于 `比例 × (父容器尺寸 − 当前按钮尺寸)`。编辑区扣除工具栏，HUD 用自己的容器尺寸回算。容器缩放时终止正在进行的拖动并按比例重新投影。初次进入若尺寸还未就绪，延后布局。

按下时记录所属指针、起始指针位置及按钮起点。移动使用相对位移，抬起和取消都消费最后一次有效坐标并解除捕获。PC 快速移出按钮时，引擎可能只发下按和取消，终点在取消事件上。编辑时启用 PC 鼠标模拟触摸，离开或销毁时释放。正常 HUD 使用自己的操作回调。分享码只解析带版本的 JSON；先校验整份数据和数值范围，再替换草稿。

示例的配置保存在本客户端的全局配置域，跨世界回显。一个设备上需要按账号隔离时，沿用目标项目的账号键。读取失败或遇到未知版本时保留现存记录，保存失败留在编辑页。缺省字段按按钮默认值回填。

## 验收

首次打开空存档，拖一个短距离、拖到四边，再拖到画布外松开。调整大小和透明度，验证保存后 HUD 的实际热区与画面一致；再次打开、取消一次修改、重进世界，核对回显。重复一次复制和导入，试错版本、缺字段与越界数值。缩放 GUI 或更换宽高比时检查按钮边界、重叠选择和工具栏可达性。分别记录鼠标模拟触摸和真实触屏的结果。
